Required Libraries:

    DHT Sensor Library: For interfacing with the DHT11 sensor.
    TM1637Display Library: For controlling the TM1637 display.

You can install these from the Arduino Library Manager.
Wiring:

    DHT11 Sensor:
        VCC → 5V
        GND → GND
        DATA → Pin 2 (for example)

    TM1637 Display:
        CLK → Pin 3 (for example)
        DIO → Pin 4 (for example)
        VCC → 5V
        GND → GND

Required Libraries:
    OneWire for communicating with the DS18B20 sensor.
    DallasTemperature to handle temperature readings from the DS18B20.
